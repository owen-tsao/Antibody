Antibody

Self-healing for AI agents

Four agents, one loop
How it works
01ChaosAttacks the agent, then adapts to every fix.
02TargetThe support agent under test. Real tools, real tickets.
03JudgeProves what actually went wrong.
04RepairWrites the fix. Code first, prompts last.
05GateLets a fix through only if nothing else breaks.
What each agent does
The team
01
Chaos
  • Hides instructions inside a ticket's internal notes.
  • Breaks a tool so it returns nothing, or talks its way into a refund on someone else's order.
  • Reads why the last attack got blocked and tries a different way in.
02
Target
  • A customer-support agent running on Llama 3.1 8B through W&B Inference.
  • Reads the ticket, looks up orders, issues refunds, sends email.
  • Never knows it's being tested.
03
Judge
  • Checks the facts first: did a refund fire that nobody asked for? Did it open a ticket it wasn't assigned?
  • Asks a bigger model only when the rules can't decide.
  • Every verdict is a Weave trace you can open and audit.
04
Repair
  • Proposes one fix at a time.
  • Prefers tool rules and output validators over prompt edits, so the LLM stops being the security layer.
  • Remembers what got rejected and never tries it twice.
Gate
  • Three Weave evaluations: stops the new attack, still stops every old one, legitimate customers still get helped.
  • Anything less is rejected, and Repair tries again.
