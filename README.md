# Chaos Monkey for Agents

Chaos engineering for AI agents: a chaos agent deliberately breaks a production agent (adversarial users, failing tools, ambiguous requests), every failure becomes a permanent regression eval in Weave, and a repair agent patches the defense. Patches only ship if they fix the break without regressing normal users. The loop repeats, and the agent gets measurably more reliable every cycle.

Built at CoreWeave Hacks (Agent Loops), September 12–13, 2026.

This repo currently contains only planning documents. All code will be written on-site during the hackathon.
